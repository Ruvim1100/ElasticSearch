M00-L01Welcome

Добро пожаловать в Elasticsearch Engineering Academy

Наша задача — довести навыки от понимания термина index до защиты полноценной поисковой платформы с интеграцией .NET, синхронизацией с PostgreSQL, мониторингом, security и relevance evaluation.

Источник истины — Tracker: прогресс фиксируется только после демонстрации знаний и проверки артефактов. Отметка «просмотрел урок» не означает «усвоил».

Как выглядит цикл урока

  1. Прочти цель и prerequisites (что понадобится).
  2. Пройди теорию и визуализацию, сформулируй концепт своими словами.
  3. Выполни практические упражнения; собери воспроизводимые артефакты.
  4. Ответь на вопросы в конце; не подглядывай в ключ во время решения.
  5. Отправь код / запросы / README наставнику на строгую проверку.
  6. Исправь замечания. Только после этого получаешь Verified и следующую тему.

Что считается доказательством

Ответ, который можно проверить: тесты, JSON-запросы с ожидаемым результатом, документированный diff, схема с обоснованием, benchmark с условиями. Скриншот без объяснения и копия чужого кода — не доказательство.

Оценивание

Для урока: теория ≥ 80%, практика ≥ 90%, способность объяснить решение. Для модульного экзамена: теория 25%, практика 55%, архитектура 20%; проходной результат ≥ 80% и отсутствие критических ошибок.

Первое действие

  1. Открой вкладки Dashboard, Modules, Lessons, Rubric.
  2. Пройди M00-L02 диагностикой: 5–10 вопросов по HTTP/JSON/SQL, чтобы не повторять известное.
  3. Открой M01-L01, чтобы увидеть, как выглядит полноценный интерактивный урок.
